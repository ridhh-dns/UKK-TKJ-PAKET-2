Spesifikasi Ujian
Interface / Perangkat Fungsi Jaringan Alamat IP / Subnet Gateway / DNS Keterangan Port
ether1 (Router) Jalur Internet ISP 10.10.10.xx/24 GW: 10.10.10.254 | DNS: 8.8.8.8 NAT Masquerade & Dst-NAT 9090
ether2 (Router) Jaringan Server VM 192.168.xx.1/29 - Segment Server Private Cloud
web-xx (VM Web) LMS Moodle Web Server 192.168.xx.2/29 GW: 192.168.xx.1 HTTP Port 80 (Internal)

ether3 (Router) Jaringan Klien Lokal 192.168.100.1/24 - DHCP Server: 192.168.100.2 - 50
PC Client Komputer Penguji / Siswa 192.168.100.xx/24 GW: 192.168.100.1 Static / DHCP Client
PENTING: Ganti variabel xx pada alamat IP dan nama mesin dengan nomor meja / nomor absen ujian Anda (contoh: bila nomor meja 14, maka IP ether1 adalah 10.10.10.14/24).

Bagian 1 Konfigurasi Router MikroTik: IP Address, NAT, DHCP & DNS

1.1 Alamat IP pada Tiga Interface Router

1 Langkah 1

Jalankan aplikasi WinBox di komputer admin, kemudian sambungkan ke router MikroTik agar panel konfigurasinya terbuka.

2 Langkah 2

Masuk ke menu IP di sidebar kiri WinBox, pilih submenu Addresses, lalu tekan ikon tambah (+) untuk mulai menambahkan alamat IP baru.

3 Langkah 3

Lengkapi alamat IP pada interface ether1, yaitu jalur internet dari ISP, dengan 10.10.10.xx/24.

4 Langkah 4

Lanjut ke interface ether2 yang mengarah ke jaringan VirtualBox VM; isi alamatnya dengan 192.168.xx.1/29.

5 Langkah 5

Terakhir, atur interface ether3 untuk jaringan lokal int-client memakai alamat 192.168.100.1/24.

1.2 NAT Gateway & Port-Forwarding LMS

6 Langkah 6

Masuk ke menu IP > Firewall di WinBox untuk membuka halaman pengaturan firewall.

7 Langkah 7

Pindah ke tab NAT, kemudian buat rule baru dengan menekan tombol tambah (+).

8 Langkah 8

Pada tab General, atur Chain: srcnat dengan Out. Interface: ether1 supaya rule ini mengurus trafik akses internet gateway.

9 Langkah 9

Di tab Action, jadikan Action: masquerade sebagai pilihan, lalu simpan dengan menekan OK.

10 Langkah 10

Buat rule kedua untuk Port Forwarding (Destination NAT): isi Chain: dstnat dengan In. Interface ether1 dan protocol tcp (6), sehingga trafik luar yang datang ke IP ISP pada port 9090 dapat diterima.

11 Langkah 11

Masih di tab Action, pilih Action: dst-nat, arahkan To Addresses ke IP VM Web Server (192.168.xx.2) dan To Ports: 80.

1.3 Penyewaan IP Otomatis (DHCP)

12 Langkah 12

Buka menu IP > DHCP Server untuk mulai menyiapkan layanan DHCP.

13 Langkah 13

Setelah jendela DHCP Server tampil, tekan tombol DHCP Setup agar wizard konfigurasi mulai berjalan.

14 Langkah 14

Dalam wizard DHCP Setup, tetapkan interface jaringan lokal yang dipakai, yaitu ether3 / int-client.

15 Langkah 15

Tentukan rentang alamat IP (Addresses to Give Out) yang nantinya dibagikan kepada client.

16 Langkah 16

Isi DNS Server yang ikut diberikan ke client DHCP, kemudian selesaikan wizard sampai proses setup benar-benar tuntas.

1.4 Gateway ISP & DNS Publik

17 Langkah 17

Buka menu IP > Routes; dari daftar tabel routing yang tampil, tekan tombol tambah (+) supaya entri route baru dapat dibuat.

18 Langkah 18

Isi kolom Gateway dengan alamat IP gateway milik ISP yang terhubung melalui jalur ether1.

19 Langkah 19

Simpan konfigurasi route tersebut, kemudian yakinkan diri bahwa keterangan statusnya sudah aktif (AS, Active Static).

20 Langkah 20

Selanjutnya buka menu IP > DNS untuk mengatur server DNS pada router.

21 Langkah 21

Isi kolom Servers dengan DNS Google (8.8.8.8), beri tanda centang pada Allow Remote Requests, lalu akhiri dengan menekan OK.

1.5 Konfigurasi Client & Uji Ping

22 Langkah 22

Di PC Client, panggil kotak dialog Run (Win + R) lalu ketikkan ncpa.cpl untuk membuka jendela Network Connections.

23 Langkah 23

Dari daftar koneksi yang ditampilkan, pilih adapter Ethernet yang sedang digunakan.

24 Langkah 24

Buka jendela Status/Properties milik adapter Ethernet tersebut.

25 Langkah 25

Sorot item Internet Protocol Version 4 (TCP/IPv4), lalu tekan tombol Properties.

26 Langkah 26

Masukkan konfigurasi IP statis untuk sisi client, kemudian simpan pengaturannya dengan menekan OK.

27 Langkah 27

Kembali ke WinBox dan pilih menu New Terminal; jendela CLI router akan terbuka dan siap menerima perintah pengujian.

28 Langkah 28

Jendela CLI Terminal MikroTik kini terbuka dan siap dipakai untuk mengetikkan perintah.

29 Langkah 29

Uji konektivitas jaringan dari terminal menggunakan perintah ping, dan pastikan hasilnya reply.

Bagian 4 Pengesahan Jaringan, Repositori APT & Duplikasi VM

Tahap A — Verifikasi Jaringan & Repositori APT

1 Langkah 1

Periksa alamat IP yang tersedia pada interface jaringan VM Web Server.

bash 
ip a
2 Langkah 2

Pastikan koneksi internet VM berjalan baik dengan melakukan ping ke moodle.org.

bash 
ping moodle.org
3 Langkah 3

Tuliskan daftar repositori resmi network mirror Debian ke dalam file /etc/apt/sources.list.

bash 
nano /etc/apt/sources.list
4 Langkah 4

Segerakan pembaruan indeks daftar paket agar mengikuti repositori Debian terbaru.

bash 
apt update

Tahap B — Duplikasi VM: Web Server → Database Server

5 Langkah 5

Matikan VM Web Server terlebih dahulu, kemudian buka menu Clone di VirtualBox.

Ganti nama hasil clone menjadi db_server dan pastikan tipe yang dipilih adalah Full Clone.

Selanjutnya buka pengaturan Network Bridged Adapter milik db_server, lalu lakukan Refresh MAC Address supaya tidak sama dengan Web Server.

6 Langkah 6

Sesuaikan alamat IP statis pada db_server hingga menjadi 192.168.xx.3/29.

bash 
nano /etc/network/interfaces

Terapkan perubahan alamat IP di db_server, lalu validasi hasilnya dengan perintah ip a.

bash 
systemctl restart networking
ip a

Bagian 5 Penyediaan Database Server MariaDB

1 Langkah 1

Pasang MariaDB, kemudian ubah nilai bind-address dari 127.0.0.1 menjadi 0.0.0.0 supaya database dapat dijangkau secara remote dari VM Web Server.

bash 
apt install mariadb-server -y
nano /etc/mysql/mariadb.conf.d/50-server.cnf
bash 
systemctl restart mariadb
2 Langkah 2

Masuk ke konsol MariaDB, lalu siapkan database moodle beserta hak akses penuh untuk moodleuser yang berasal dari IP Web Server.

bash 
mysql -u root -p
sql 
CREATE DATABASE moodle DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'moodleuser'@'192.168.3.2' IDENTIFIED BY '1';
GRANT ALL PRIVILEGES ON moodle.* TO 'moodleuser'@'192.168.3.2';
FLUSH PRIVILEGES;
EXIT;

Bagian 6 Pembangunan Web Server & Penerapan LMS Moodle

6.1 Stack Web & Unduhan Source Moodle

1 Langkah 1

Pasang Apache2, PHP beserta seluruh modul yang dibutuhkan, lalu unduh file arsip Moodle ke dalam direktori /var/www/html.

bash 
apt install apache2 mariadb-client php libapache2-mod-php php-mysql php-xml php-mbstring php-curl php-zip php-gd php-intl php-soap -y
cd /var/www/html
wget https://download.moodle.org/download.php/direct/stable503/moodle-latest-503.tgz
2 Langkah 2

Ekstrak arsip Moodle tersebut, pindahkan file .tgz ke /etc, keluarkan seluruh isi folder moodle ke /var/www/html, dan pastikan hasilnya lewat ls.

bash 
tar -zxvf moodle-latest-503.tgz
mv moodle-latest-503.tgz /etc
mv moodle/* .
ls
3 Langkah 3

Bentuk folder /var/www/moodledata baru, lalu atur kepemilikan (owner) dan izin akses (permission) untuk pengguna www-data.

bash 
mkdir -p /var/www/moodledata
chown -R www-data:www-data /var/www/html
chown -R www-data:www-data /var/www/moodledata
chmod -R 770 /var/www/moodledata
chmod -R 755 /var/www/html

6.2 VirtualHost Apache & php.ini

4 Langkah 4

Ubah arahan DocumentRoot agar menunjuk ke /var/www/html/public.

bash 
nano /etc/apache2/sites-available/000-default.conf
5 Langkah 5

Buang tanda komentar (;) pada baris max_input_vars dan naikkan nilainya menjadi 5000.

bash 
nano /etc/php/8.2/apache2/php.ini
bash 
systemctl restart apache2

Bagian 7 Otomatisasi Pencadangan Bash Script & Cron

7.1 Cronjob Backup Web Server

1 Langkah 1

Susun script backup web server (backup_web.sh) yang bertugas mengompresi berkas konfigurasi serta data web server ke direktori /backup.

bash 
nano /usr/local/bin/backup_web.sh

Berikan izin eksekusi pada script tersebut, lalu jalankan sekali secara manual untuk memastikannya bekerja.

bash 
chmod +x /usr/local/bin/backup_web.sh
/usr/local/bin/backup_web.sh
2 Langkah 2

Buka konfigurasi penjadwalan cronjob (pilih 1 agar editor yang digunakan nano) dan tambahkan baris jadwal yang menjalankan /usr/local/bin/backup_web.sh secara otomatis.

bash 
crontab -e
3 Langkah 3

Intip isi direktori /backup guna memastikan arsip hasil backup web server benar-benar terbentuk.

bash 
ls /backup

7.2 Cronjob Backup Database Server

4 Langkah 4

Buat script backup database (backup_db.sh) yang menyalin isi database Moodle ke dalam direktori /backup.

bash 
nano /usr/local/bin/backup_db.sh

Terapkan izin eksekusi pada script backup database, lalu eksekusi manual terlebih dahulu sebagai uji coba.

bash 
chmod +x /usr/local/bin/backup_db.sh
/usr/local/bin/backup_db.sh
5 Langkah 5

Masuk ke konfigurasi cronjob (pilih 1 untuk memakai editor nano) dan sisipkan jadwal otomatis yang mengeksekusi /usr/local/bin/backup_db.sh.

bash 
crontab -e
6 Langkah 6

Periksa direktori /backup pada db_server untuk memastikan file hasil backup database sudah tersimpan.

bash 
ls /backup
